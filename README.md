# CRM и тестовый бот для мебельного салона

Это тестовая версия сервиса для проверки ИИ-консультанта салона корпусной мебели.

Администратор может:

- войти в CRM по логину и паролю;
- создать тестовую ссылку на диалог с ботом;
- отправить ссылку сотруднику или клиенту;
- посмотреть все диалоги в админке;
- прочитать feedback по каждому тесту;
- самому дополнить feedback и заметки по диалогу.

## Как войти в админку

1. Откройте ссылку на CRM в браузере.
2. Если открылась форма входа, введите логин и пароль администратора.
3. Нажмите `Войти`.

Логин и пароль выдаёт тот, кто устанавливал сервис на сервер.

Если пароль не подходит, не пытайтесь подбирать его много раз подряд: система временно ограничивает частые попытки входа.

## Главная страница админа

После входа откройте раздел `Админка`.

В админке видна таблица диалогов. В ней можно посмотреть:

- когда диалог был обновлён;
- на каком шаге сейчас находится бот;
- имя клиента, если бот уже его узнал;
- краткий запрос клиента;
- предварительную сумму, если расчёт уже появился;
- есть ли тестовая ссылка;
- оставлен ли feedback.

Чтобы открыть подробности, нажмите `Открыть` рядом с нужным диалогом.

## Как создать тестовую ссылку

1. В админке нажмите кнопку `Создать тестовую ссылку`.
2. Сервис создаст новый пустой диалог и покажет ссылку.
3. Скопируйте эту ссылку.
4. Отправьте её сотруднику или клиенту.

Ссылка действует 4 часа с момента создания. После этого она перестанет открываться.

Важно: ссылка даёт доступ только к одному тестовому диалогу. Человек по ссылке не попадёт в админку и не увидит другие диалоги.

## Как дать ссылку сотруднику или клиенту

Отправьте ссылку обычным способом: в Telegram, WhatsApp, SMS или по email.

Можно написать так:

```text
Здравствуйте! Это тест нашего ИИ-консультанта по мебели на заказ.
Пожалуйста, пройдите короткий диалог и в конце оставьте впечатления в поле feedback.
Ссылка действует 4 часа.
```

## Что видит человек по тестовой ссылке

По ссылке открывается простая страница:

- чат с ИИ-консультантом;
- сообщение о том, что ссылка действует 4 часа;
- поле `Feedback`;
- кнопка `Сохранить feedback`.

В поле feedback человек может написать, что понравилось, что было непонятно, где бот ошибся или какие вопросы показались лишними.

## Где посмотреть feedback

1. Откройте админку.
2. Найдите нужный диалог в таблице.
3. Нажмите `Открыть`.
4. В карточке диалога найдите блок `Тестовая ссылка`.

Там будет feedback, который оставил тестировщик.

Администратор тоже может отредактировать или дополнить feedback и нажать `Сохранить feedback`.

## Как посмотреть сам диалог

1. Откройте диалог в админке.
2. Перейдите во вкладку `Чат`.

Там видна переписка клиента с ботом.

Также доступны вкладки:

- `Профайл` - краткое описание клиента и его запроса;
- `ТЗ` - техническое задание для дизайнера или технолога;
- `Спецификация` - таблица позиций, которую можно править руками;
- `Расчёт` - предварительная цена, если данных достаточно.

## Если нужно отправить ссылку ещё раз

Если старая ссылка истекла или её нужно заменить:

1. Откройте нужный диалог в админке.
2. В блоке `Тестовая ссылка` нажмите `Перегенерировать ссылку`.
3. Скопируйте новую ссылку.

Старая ссылка после этого перестанет работать.

## Защита от спама

Тестовая ссылка специально сделана длинной и неподбираемой.

Также сервис ограничивает слишком частые действия:

- частые попытки входа;
- слишком много сообщений в публичном тестовом диалоге;
- слишком частое сохранение feedback.

Если пользователь увидел ошибку про слишком много запросов, нужно подождать пару минут и попробовать снова.

## Что делать, если бот ответил плохо

Не удаляйте такой диалог сразу.

Лучше:

1. Откройте диалог в админке.
2. Посмотрите вкладку `Чат`.
3. В блоке feedback кратко напишите, что пошло не так.
4. Если feedback уже оставил клиент или сотрудник, дополните его своим комментарием.

Такие диалоги полезны: по ним можно улучшать prompt бота и сценарий общения.

## Технический запуск для разработчика

Локально сервис запускается через Docker Compose:

```bash
docker compose up --build
```

Адреса по умолчанию:

- frontend: `http://localhost:5173`
- backend: `http://localhost:8080`
- админка: `http://localhost:5173/admin`

Для работы нужно заполнить `.env`: `OPENAI_API_KEY`, данные Postgres, логин и пароль администратора.

## OpenAI через proxy на VPS

Если сервер не может напрямую обращаться к OpenAI API, включите outbound proxy в `.env`:

```env
OUTBOUND_PROXY_ENABLED=true
OUTBOUND_PROXY_URL=http://proxy_user:proxy_password@10.77.77.1:3128
OUTBOUND_PROXY_NO_PROXY=localhost,127.0.0.1,postgres,backend,frontend
OUTBOUND_PROXY_TIMEOUT_MS=30000
OPENAI_USE_PROXY=true
```

После изменения `.env` перезапустите backend или весь Docker Compose.

Если proxy не нужен, оставьте:

```env
OUTBOUND_PROXY_ENABLED=false
```
